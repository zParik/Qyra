# Tesseract language data

`eng.traineddata` is the English LSTM model from
[tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)
(`main`, SHA-256 `7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2`),
licensed under the Apache License 2.0. MuPDF's built-in tesseract loads it
for the offline OCR tool.
